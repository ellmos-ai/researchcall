# _shared — gilt fuer die ganze Pipeline

Was hier liegt, gilt in **jeder** Station. Stationsspezifisches gehoert in den jeweiligen
Stationsordner.

| Ordner | Inhalt |
|---|---|
| `connectors/` | Anschluesse nach aussen: Export, Import, Mail, Kalender, Datenquellen |
| `tools/` | Werkzeuge, die in mehreren Stationen gebraucht werden |
| `policies/` | Regeln, die ueberall gelten — plus die Vorlage fuer eigene Policies |
| `templates/` | Vorlagen, die stationsuebergreifend benutzt werden |
