# Policies — Regeln, die ueberall gelten

Hier liegen die Regeln, die nicht an eine Station gebunden sind. `USER-POLICY.template.md`
ist die Vorlage fuer eigene.

## Fest eingebaut (nicht abschaltbar)

| Regel | Wo sie greift |
|---|---|
| Ausdrueckliche Zustimmung vor jeder Erhebung | 3, 6 |
| Jederzeitiges Abbruchrecht | 3, 6 |
| Rohantwort neben der Deutung aufbewahren | 6, 7 |
| Nachtraegliche Ergaenzungen werden markiert | alle |
| Aenderungen an Auswertungsregeln werden protokolliert | 2, 7 |
| Rufnummern in Ausgaben maskiert | alle |
| Quellencheck vor Veroeffentlichung | 8 |

## Prioritaet

`absolute` schlaegt `high` schlaegt `normal`. Kollidieren zwei Policies gleicher
Prioritaet, entscheidet der Nutzer — der Agent fragt, statt zu waehlen.
